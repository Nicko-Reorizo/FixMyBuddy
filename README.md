# FixMyBuddy

## Customer app

The React and Tailwind customer web app lives in `frontend/customer-side/`.
The mechanic-side app can be maintained separately under `frontend/` alongside it.

From the repository root, run:

```powershell
cd frontend/customer-side
npm.cmd install
npm.cmd run dev
```

See [frontend/customer-side/README.md](frontend/customer-side/README.md) for configuration and API documentation.
